# Deployment checklist

1. Push the `main` branch of `Saikumararava/PortfolioReact` to GitHub.
2. In Vercel, confirm that the project `portfolio-react-inky-mu` is connected to this repository and that the production branch is `main`.
3. Confirm Build Command `npm run build` and Output Directory `dist`.
4. Deploy and open both `/` and `/experience` on desktop and mobile.
5. Download `/Sai-Kumar-Resume.pdf` and verify that the current copy opens.

A connector commit does not itself prove that Vercel ran a build or deployed the result. Check the Vercel deployment status before changing the URL on a resume sent to recruiters.
